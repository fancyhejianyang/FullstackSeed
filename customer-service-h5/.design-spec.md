# Project Design Specification

## 1. Design Style
- Aesthetic: Ultra-Minimalism（超极简）+ Tech（科技感）
- Key Characteristics:
  - 大留白、克制配色、细线描边、柔和圆角、极淡阴影
  - 深色背景营造科技氛围，界面聚焦聊天内容本身
  - 所有装饰元素克制，不为装饰而装饰

## 2. Color Palette
- Background: `#0B0F14`（深空黑，主背景）
- Surface: `#141A22`（卡片 / 输入区 / 客服气泡）
- Primary: `#38BDF8`（科技青蓝，主强调色）
- Accent: `#22D3EE`（亮青，渐变点缀）
- Text Primary: `#F1F5F9`（主文字）
- Text Secondary: `#94A3B8`（次要文字 / 时间戳）
- Border: `rgba(255, 255, 255, 0.08)`（细分隔线）
- User Bubble: `#38BDF8`（用户消息气泡）
- AI Bubble: `#141A22`（客服消息气泡）

## 3. Typography
- Font Stack: `-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Segoe UI", "Microsoft YaHei", sans-serif`
- Navigation Title: 17px / 600（顶部栏标题）
- Message Body: 15px / 1.5（消息正文）
- Meta Text: 12px（时间戳 / 辅助信息）
- Numeric / Time: 使用 `font-variant-numeric: tabular-nums`

## 4. Iconography
- Library: 内联 SVG（纯 H5 项目不引入图标库）
- Style: 细线风格，`stroke-width: 1.5`，圆角端点
- Icons:
  - Logo：聊天气泡 + 发光圆点（顶部栏左侧，圆形底托 32px / 图标 20px）
  - 客服头像：机器人轮廓（消息流内，32px 圆形底托）
  - 新聊天：加号 +
  - 历史会话：时钟（顶栏，位于加号左侧）
  - 发送：纸飞机（输入栏右侧，圆形按钮，禁用时 40% 透明）
  - 删除：垃圾桶（历史抽屉内每条会话右侧）

## 5. Logo
- Concept: 聊天气泡 + 发光圆点（AI 拟人化标识）
- Placement: 顶部栏左侧，置于圆形底托内
- Scaling: 底托 32px，图标 20px

## 6. Layout & Components
- 三段式纵向布局（flex column，占满视口）：
  - Header（固定顶栏，含毛玻璃 `blur(16px)` + 底边线）
  - MessageList（滚动消息流，`overscroll-behavior: contain`）
  - InputBar（固定底栏，毛玻璃）
- 安全区适配：`padding-top: env(safe-area-inset-top)` / `padding-bottom: env(safe-area-inset-bottom)`
- 圆角令牌：`--radius-lg: 20px` / `--radius-md: 14px` / `--radius-sm: 10px`
- 阴影：`--shadow-soft: 0 8px 24px rgba(0,0,0,0.35)`

## 7. Interactive States
- 用户消息：右侧青蓝渐变气泡（`#38BDF8 → #0EA5E9`），深字，右上圆角收小
- 客服消息：左侧深色气泡（`#141A22`）+ 细线边框 + 柔和阴影，左上圆角收小，带机器人头像与昵称行（`AI 客服 · SID xxxxxxxx` 显示 sessionId 前 8 位）
- 正在输入：三点跳动指示器（`typing-bounce` 动画）
- 流式输出：气泡内闪烁光标（`typing-cursor`，`cursor-blink` 0.8s）
- 日期分隔：居中胶囊（`今天`）
- 历史抽屉：右侧滑入（`transform: translateX`），背景遮罩 `rgba(0,0,0,.5)`，宽 `min(320px, 85vw)`
- 发送按钮：空输入时 `disabled` + 40% 透明
- 在线状态点：绿色脉冲小点（顶部状态行 `在线 · 智能助手`）

## 8. Motion
- 消息入场：`msg-in`（0.25s，上移淡入）
- 打字机光标：`cursor-blink` 0.8s step-end
- 三点指示：`typing-bounce` 1.2s
- 抽屉滑入：0.28s ease
- 发送按钮按下：`scale(0.92)`
